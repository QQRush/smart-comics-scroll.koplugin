# Smart Comics Scroll v0.1.0-beta

First public beta for KOReader. Adds landscape full-width comic scrolling, FIT SCAN, thin separator detection, optional top trimming, and a gesture-accessible ON/OFF switch.

**Install:** Extract the ZIP and copy `smartcomicsscroll.koplugin` into KOReader's `plugins/` folder, then restart KOReader.

**Known limitations:** beta tested on a limited set of CBZ files; no automatic rotation or panel recognition. Please report missed separators or unexpected blank space with visual debug screenshots.
