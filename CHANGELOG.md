# Changelog

## v0.1.0-beta — 2026-10-11

- Initial public beta of Smart Comics Scroll for KOReader.
- Landscape-oriented, full-width comic reading.
- FIT SCAN with separator-aware navigation and thin-gutter detection.
- Configurable page-end reduction and optional Top Trim.
- Gesture-accessible ON/OFF control.
- Optional visual diagnostics.

This beta has been tested on sample comics; wider device compatibility remains to be verified.
